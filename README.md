# End-to-End FMCG Data Engineering Project – Dabur India Case Study

## Project Overview

This academic project demonstrates an end-to-end FMCG data engineering pipeline using Dabur India as the case-study organization.

The project uses publicly available and/or simulated FMCG datasets to demonstrate data ingestion, data processing, data transformation, data quality, and business analytics.

## Technology Stack

* Databricks
* Apache Spark / PySpark
* Delta Lake
* SQL
* Power BI
* GitHub
